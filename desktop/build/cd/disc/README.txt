COLOMBO: SHADOWS OF THE ISLAND
Shaun David Studios
==============================

INSTALLING
  1. Put the disc in the drive. If Windows asks what to do with it, choose "Run setup.exe".
  2. If nothing happens, open the disc in File Explorer and double-click  Start.hta  (menu with the
     game logo) or  setup.exe  (the installer itself).
  3. Follow the installer. You can choose the install folder. A desktop shortcut and a Start menu
     entry (Shaun David Studios > COLOMBO Shadows of the Island) are created.
  4. The game starts when setup finishes. After that the disc is not needed to play.

  If Windows SmartScreen shows "Windows protected your PC", click "More info" and then "Run anyway"
  (the installer is not code-signed).

REQUIREMENTS
  Windows 10 or 11, 64-bit. A graphics card with WebGL 2 support (any GPU from the last ~8 years).
  8 GB RAM recommended. About 500 MB of free disk space.

PLAYING
  F11 = fullscreen. Saved games are kept between launches.

UNINSTALLING
  Settings > Apps > Installed apps > COLOMBO: Shadows of the Island > Uninstall.
